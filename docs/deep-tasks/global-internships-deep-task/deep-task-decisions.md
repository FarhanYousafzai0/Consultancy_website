## Locked decisions

- Use a separate `Internship` collection for MVP.
- Preserve existing scholarship behavior and tests.
- Use one fresh agent per epic, sequentially on the current branch.
- No new packages without explicit review.
- Official source and application URLs are required for publication.
- Unknown facts remain unknown; AI may not invent deadlines, funding, benefits, or eligibility.
- Uncertain records require admin review and remain hidden publicly.
- Public status is calculated, not independently edited.
- The first source registry must contain curated official sources across the approved source categories.
- The final verification agent must run the full test suite, lint, TypeScript validation, production build, and `git diff --check`.
